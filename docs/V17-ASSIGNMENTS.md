# V17 — Assignments & Submissions

Adds the first assignment workflow.

Lecturer:
- Create assignment
- Select module
- Add title and instructions
- Set deadline and maximum mark
- Add optional attachment URL
- View published assignments

Student:
- View assignments for registered modules
- View deadline and maximum mark
- Open attachment
- Submit using a file URL in this prototype

Run `supabase/v17_assignments_rls.sql` in Supabase.

Production next step: replace the prototype URL submission with Supabase Storage upload and signed URLs. Then add lecturer marking/comments and submission status.
