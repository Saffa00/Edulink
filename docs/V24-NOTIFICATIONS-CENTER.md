# V24 — Notifications Center

V24 provides a shared notification center for Student and Lecturer accounts.

Features:
- All notifications
- Unread-only filter
- Unread count
- Mark all as read
- Notification timestamp
- Notification type metadata
- Notification bell with unread badge
- Strict RLS so users can only read/update their own notifications

Supported notification types can include grade, assignment, attendance, dissertation, system, and message.
